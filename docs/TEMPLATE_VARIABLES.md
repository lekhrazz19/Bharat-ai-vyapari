# Template Variables

Service pages expect each service object to contain:

- serviceSectionLabel
- serviceName
- serviceTagline
- whoItsForTitle
- whoItsForDescription
- industry1 ... industry12
- useCaseTitle
- useCaseSummary
- resultTitle
- resultStatement
- workflowTitle
- step1Title ... step5Bullet4
- benefitsTitle
- pasTitle
- outcomeHeader
- beforeHeader
- afterHeader
- outcome1/before1/after1 ... outcome6/before6/after6
- problemTitle/problemText
- agitationTitle/agitationText
- solutionTitle/solutionText
- pricingPlan/setupCost/monthlyCost/timeline/nextStep
